# Airbnb Clone Project

## Overview
The Airbnb Clone Project is a full-stack web application designed to replicate the core functionalities of Airbnb. This project serves as a hands-on learning experience to build a scalable booking platform while implementing modern software development practices. It covers backend architecture, database design, API development, security, and CI/CD pipelines.

## Project Goals
- Develop a robust, scalable booking platform similar to Airbnb
- Master collaborative team workflows using GitHub
- Implement secure API endpoints with proper authentication and authorization
- Design an efficient relational database structure
- Set up automated CI/CD pipelines for seamless deployment
- Document the development process and system architecture
- Integrate multiple technologies into a unified ecosystem

## Tech Stack
### Backend
- **Framework**: Django (Python)
- **API**: GraphQL (with Django Graphene)
- **Authentication**: JWT (JSON Web Tokens)

### Database
- **Primary Database**: Postgres
- **ORM**: Django ORM

### DevOps & Deployment
- **Containerization**: Docker
- **CI/CD**: GitHub Actions
- **Platform**: AWS

### Frontend
- **Framework**: React.js (JavaScript)

### Other Tools
- **Version Control**: Git/GitHub
- **Documentation**: Markdown
- **Project Management**: GitHub Projects (or similar)
